# R1-A1-S1 Redes Neuronales básicas

Implementación desde cero en Python de tres modelos de clasificación binaria:

- Perceptrón simple
- Red neuronal de una capa
- Red neuronal multicapa (vainilla)

Se incluye el ejemplo de la compuerta XOR como diferenciador
de la red multicapa.

## Requisitos

- matplotlib

en Jupyter, Colab o VS Code.
